Courbe d'efficacite d'un plan d'echantillonnage

Source : P26_TD1, Exercice 3, deuxieme controle, question 3.

Pa(p) = probabilite d'accepter le lot.

Quand p augmente, un bon plan doit accepter de moins en moins souvent.

Comment faire ce type de question

1. Lire le plan

Le lot contient 10 000 comprimes. L'echantillon represente 5 %, donc n = 500.

2. Lire la regle

"Pas plus de 20 non conformes" signifie : accepter si X <= 20. Donc A = 20 et R = 21.

3. Ecrire la courbe

Pour chaque taux de non-conformes p, on calcule la probabilite d'accepter.

Pa(p) = P(X <= 20)
X suit B(500, p)
Pa(p) = somme k=0..20 C(500,k) p^k (1-p)^(500-k)
4. Dessiner

Axe horizontal : p, le pourcentage de non-conformes. Axe vertical : Pa(p), la probabilite d'accepter.
