Plan progressif : lire An, Bn et la decision

Source : P26_TD2, Exercice 3. Exemple montre le cas d'un lot sans defaut.

Regle de lecture

Apres chaque piece controlee, on compare le cumul des defauts x_n avec deux lignes.

Acceptation

Si x_n <= An, on accepte le lot.

Rejet

Si x_n >= Bn, on refuse le lot.

Sinon

Si An < x_n < Bn, on continue le prelevement.

Cas sans defaut

Le cumul reste x_n = 0. On accepte des que 0 <= -3,49 + 0,07n, donc a n = 50.
