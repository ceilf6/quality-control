# I. 统计表

## A. 标准正态分布表 N(0,1)

**标准正态分布 N(0,1) 的分布函数表**：表示找到一个小于 `u` 的值的概率，即：

`P = F(u) = P(X < u)`

原 PDF 第 1—2 页给出了标准正态分布函数表。表中：

- 左侧第一列表示 `u` 的整数位和十分位；
- 表头横向表示 `u` 的百分位；
- 表格内部数值表示 `P(X < u)`。

### 如何读取该表

读取该表时，只需要：

1. 在表格内部寻找所需概率值，概率范围通常从 `0.5` 到 `1`；
2. 根据该概率值所在的位置，确定对应的边界值 `u`。

**例 1：**

对于 `α = 0.8`，根据表格可得：

`u ≈ 0.84`

读取方式是：

- 纵轴读取个位和十分位；
- 横轴读取百分位。

**注意：**

如果概率 `α < 0.5`，则需要先计算 `1 - α`，在表中查找对应的边界值，然后取该值的相反数。

**例 2：**

对于 `α = 0.25`：

`1 - α = 0.75`

由表可得：

`|u| ≈ 0.675`

因此最终得到：

`u = -0.675`

如果要根据边界值确定对应概率，则按相同步骤反向查表即可。

**例 3：**

对于 `u = 2.23`：

- 将边界值拆为 `2.2 + 0.03`；
- 在表中定位到对应行和列；
- 读取概率：

`α = 0.9871`

# II. 接收检验用表

这些表属于标准：**NFX 60-022 / MIL STD 105**。

## A. 样本量的确定：代码字母

**表 1：接收检验：代码字母**

该表根据批量大小确定代码字母。后续默认采用**一般检验 II 列**。

示例：

如果 `N = 100`，则代码字母为 `F`。

表中列含义：

- `Effectif du lot`：批量大小；
- `Contrôles généraux`：一般检验；
- `I / II / III`：不同检验水平；
- 后续默认使用 `II` 列。

---

## B. 样本量的确定：代码字母与样本量对应关系

**表 2：接收检验：代码—样本量对应表**

根据表 1 中确定的代码字母，可以在该表中查出简单检验、双重检验或多重检验所需的样本量。

表中术语：

- `Contrôle normal`：正常检验；
- `Lettre code`：代码字母；
- `Simple`：简单抽样检验；
- `Double`：双重抽样检验；
- `Multiple`：多重抽样检验；
- `n`：样本量；
- `n1, n2, ...`：第 1、第 2、……次抽样的样本量。

示例：

沿用前面的代码字母 `F`：

- 简单检验：`n = 20`；
- 双重检验：`n1 = n2 = 13`；
- 多重检验：`n1 = n2 = n3 = 5`。

---

## C. 简单抽样方案：正常、加严、放宽

**表 3：简单抽样方案参数**

主题：**不合格个体百分比**。

该表用于根据代码字母和 NQA，确定简单抽样方案的参数。

表中术语：

- `Normal`：正常检验；
- `Renforcé`：加严检验；
- `Réduit`：放宽检验；
- `Pourcentage d’individus non conformes`：不合格个体百分比；
- `Critères d’acceptation`：接收准则；
- `A`：接收数；
- `R`：拒收数；
- `NQA`：可接收质量水平；
- `P95`：接收概率为 95% 时对应的不合格百分比；
- `P10`：接收概率为 10% 时对应的不合格百分比。

使用方法：

1. 先根据前面的表确定对应代码字母；
2. 在表 3 中找到该代码字母对应的行；
3. 定位所需的 NQA；
4. 对于正常检验或加严检验，从左向右读取；
5. 对于放宽检验，从右向左读取；
6. 对应的接收准则 `A` 和拒收准则 `R` 分别在表格上方或下方读取。

示例：

若代码字母为 `F`，进行简单正常检验，且 `NQA = 4%`：

- 样本量：`n = 20`；
- 接收准则：`A = 2`；
- 拒收准则：`R = 3`。

表中每一个矩形代表一个由边界条件 `(n ; A-R)` 定义的简单抽样方案。

矩形内部：

- 上方数字表示 `P = 95%` 时的不合格百分比；
- 中间数字表示正常检验中的 `NQA`；
- 下方数字表示 `P = 10%` 时的不合格百分比；
- 如果中间数字不存在，则该矩形只表示一个加严检验方案。

## F. 对应表：简单、双重和多重抽样的接收界限

**表 6：双重—多重抽样方案参数**

该表用于在已经确定简单抽样方案的 `A` 和 `R` 后，查找对应的双重抽样或多重抽样方案参数。

表中术语：

- `Plan simple`：简单抽样方案；
- `Plans doubles`：双重抽样方案；
- `Plans multiples`：多重抽样方案；
- `Contrôle normal`：正常检验；
- `Contrôle renforcé`：加严检验；
- `Contrôle réduit`：放宽检验；
- `A-R`：简单抽样方案中的接收数—拒收数；
- `A1, A2, ...`：第 1 次、第 2 次等抽样后的接收数；
- `R1, R2, ...`：第 1 次、第 2 次等抽样后的拒收数。

使用方法：

1. 先确定简单抽样检验中的 `A` 和 `R`；
2. 在表格第一列找到对应的 `A-R`；
3. 读取相应双重抽样方案中的 `A1, A2, R1, R2`；
4. 或读取相应多重抽样方案中的 `Ai, Ri`；
5. 读取时必须区分检验类型：正常、加严或放宽。

### 备注

- 该控制只适用于每 100 个单位中平均不合格特征数的控制。
- 表中的符号 `-` 表示不允许接收零件。
- 在多重抽样的放宽检验中，如果在最后一个样本处超过接收准则但尚未达到拒收准则，则该批次被接收，但之后需要恢复正常检验。
