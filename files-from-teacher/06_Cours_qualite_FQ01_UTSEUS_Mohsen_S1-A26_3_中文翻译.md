## 统计与抽样

- 同一过程得到的两个同类产品单元并不完全相同。
- 变异是不可避免的。
- 统计学允许在考虑数据变异的情况下进行数据分析并得出结论，即推断。

基本过程：

1. 总体
2. 抽样
3. 建模、分析等

抽样用于测量产品特征，例如尺寸等。

质量控制可包括：

- 目视控制

## 最终检验与接收检验

### 全检（最高可达 100%）

优点：

- 具有不可否认的重要性

实施难点：

- 在任何情况下都存在与控制系统相关的不确定性，可能来自人或机器
- 可能是破坏性检验
- 成本高
- 实践组织困难
- 需要检查的数量很大

### 抽样控制

优点：

- 具有明显的实践意义和经济意义

缺点 / 要求：

- 与全检相比，错误风险不可避免地增加
- 需要研究并确定有效、明确的控制策略和控制协议

---

## 抽样控制

抽样控制使用随机选择零件的方法，从一个批次中选取样本。基于抽样结果，决定接受或拒收该批次。

### 目标

- 不只是直接估计某个批次的质量，而是推荐一个明确行动：**接受**或**拒收**。
- 这意味着需要估计整体的相同质量水平。

### 控制计划

- 一种具体的抽样协议，用于提供决策规则：接受或拒收某个批次。
- 一系列信息：合作协议（AP）。
- 计划类型：简单抽样、双重抽样、多重抽样、序贯抽样计划。

---

## 抽样计划的关键概念

### 水平

#### 可接受质量水平 NQA（AQL）

- 供应商过程的最低质量水平，消费者仍会将其视为过程平均水平上可以接受的质量。
- 它是供应商制造过程的属性。

#### 批次不合格容许百分比 LTPD / 极限质量水平 NQL

- 消费者愿意在单个批次中接受的最低质量水平。
- 它是由消费者指定的批次质量水平。

### 风险

#### 生产者 / 供应商风险 α

- 拒收一个可接受质量批次的概率。
- 质量水平达到或优于 NQA 的批次，最多以 α 的概率被拒收。

#### 消费者 / 客户风险 β

- 接受一个不可接受质量批次的概率。
- 质量水平达到或差于 NQL 的批次，最多以 β 的概率被抽样计划接受。

参考：Montgomery, D. C. (2007). *Introduction au contrôle statistique de la qualité*. John Wiley & Fils.

---

## 单次 / 简单抽样计划

根据现行标准以及客户与供应商之间的协议，必须识别两个质量水平 **NQA** 和 **NQL**，以及两个风险水平 **α** 和 **β**。

根据标准：当测试总体（收到的批次）中 2% 到 5% 的产品时，控制具有代表性。

---

## 计数型简单抽样计划

这是一种判定程序：从批次中随机选择 `n` 个单位组成样本，并根据样本中的信息决定该批次的处置方式。

---

## 单次抽样计划的操作

从大小为 `N` 的批次中随机抽取一个大小为 `n` 的样本并进行检查。如果发现的不合格品数量小于接受数 `A`，则接受该批次；否则拒收该批次。

- `n`：需要抽取的样本大小
- `A`：接受限 / 接受水平
- `R`：拒收限 / 拒收水平
- 假设：`R = A + 1`

---

## 单次抽样计划中的风险示意

图中展示了 NQA、NQL、界限 L、供应商风险 α 与客户风险 β 的关系：

- `α = P(X > NQA + L)`
- `β = P(Y < NQL - L)`

---

## 单次抽样计划：变量变换

若有随机变量：

```text
X = N(m, σ)
```

进行变量变换：

```text
U = (X - m) / σ
```

则：

```text
X = m + σU，且 U = N(0,1)
```

在设定界限 `L` 时，需要根据曲线上的位置处理，也可以直接根据概率值处理。

---

## 单次抽样计划：参数公式

核心关系为：

```text
L = Uα × sqrt[NQA(1 - NQA) / n] + NQA
  = NQL - Uβ × sqrt[NQL(1 - NQL) / n]
```

因此：

```text
n = [Uα sqrt(NQA(1 - NQA)) + Uβ sqrt(NQL(1 - NQL))]^2 / (NQL - NQA)^2
```

并且：

```text
A = n × L
R = A + 1
```

---

## 操作特性曲线（OC 曲线）

OC 曲线表示：在给定 AQL 水平下，批次接受概率 `Pa` 与批次不合格比例 `p` 之间的关系，其中考虑了供应商风险 `α`。

给定 `n` 和 `A` 时，对不合格比例 `p` 的接受概率为：

```text
Pa = P(X < A)
```

示例图：单次抽样计划 `n = 100` 且 `A = 3` 的 OC 曲线。

---

## OC 曲线示例

示例参数：

```text
α = 0.05
β = 0.05
NQA = 0.02
NQL = 0.15
```

理想 OC 曲线：当 `NQL → NQA` 时，`n → +∞`。

---

## 不同样本大小与接受数对 OC 曲线的影响

- 当接受数 `A` 固定时，不同样本大小会产生不同 OC 曲线。
- 当样本大小固定时，不同接受数也会产生不同 OC 曲线。
- 接受限较低的样本计划更具有判别力。

---

## 样本大小对 OC 曲线的影响

在比例 `A/n` 恒定的情况下，样本量越大，判别能力越强。

示例：

- `n = 100, c = 1`
- `n = 200, c = 2`
- `n = 300, c = 3`
- `n = 400, c = 4`
- `n = 500, c = 5`

## 军用标准 105E（ANSI/ASQC Z1.4, ISO 2859）

检验状态之间的切换：

- 正常检验
- 减量检验
- 加严检验

典型规则：

- 连续 10 批被接受，可转入减量检验
- 若有 1 批被拒收，可能从减量检验回到正常检验
- 连续 5 批中有 2 批被拒收，可转入加严检验
- 连续 5 批被接受，可从加严检验回到正常检验
- 连续 10 批仍停留在加严检验，可能停止检验 / 供货

---

## 单次抽样计划的特殊情况

### 减量检验

条件：同一供应商连续收到的 10 个批次均被接受时，需要进行减量检验。

随后，客户与供应商重新协商合作协议，将参数调整为：

```text
αD = 5 × α
nD = 0.4 × n
```

### 加严检验

条件：同一供应商收到的 5 个批次中有 2 个批次被拒收。

随后，客户与供应商重新协商合作协议，将参数收紧为：

```text
NQA_R = 0.65 × NQA
```

# 双重抽样计划

当在接受或拒收批次前需要第二个或更多样本时，使用双重抽样计划。

---

## 双重抽样计划的参数

此类计划主要由以下六个参数定义：

- 两个样本
- `n1` 和 `n2`：第一、第二样本的大小
- `A1` 和 `A2`：第一、第二样本的接受限
- `R1` 和 `R2`：第一、第二样本的拒收限
- 注意：`R2 = A2 + 1`，但 `A1` 与 `R1` 不一定满足同样关系

---

## 双重抽样计划的运行方式

1. 收到含有 `N` 件产品的批次。
2. 随机选择 `n1` 件，观察到缺陷数 `d1`。
3. 若 `d1 ≤ A1`，接受该批次。
4. 若 `d1 ≥ R1`，拒收该批次。
5. 若无法在第一样本后决策，则随机选择 `n2` 件，观察缺陷数 `d2`。
6. 若 `d1 + d2 ≤ A2`，接受该批次。
7. 否则拒收该批次。

## 使用双重抽样计划的必要条件

原文第 36 页为英文内容，主要说明如下：

- 双重抽样计划无需任何历史数据，总是可以使用。
- 使用该控制方法可能降低成本，至少不应增加成本。
- 通常 `n1 + n2` 应远大于单次样本量，或至少与其接近。
- 需要有处理两个样本的可能性，因此 `R1 > A1 + 1` 很重要；这样才能继续处理第二样本，至少针对 `A1 + 1` 的情况。
- 必须能够在最终两个样本内作出决策。
- 按假设有 `R2 = A2 + 1`。

# 序贯抽样计划

序贯抽样计划是双重抽样和多重抽样概念的扩展。

---

## 序贯抽样计划的特点

- 样本数量由抽样过程的结果决定。
- 如果每次抽样的总体大小恒定且等于 1，则该控制计划称为逐件抽样（Wald, 1947）。

此类计划主要由以下参数定义：

- 每次选择一个零件：`n1 = n2 = ... = nh = 1`（假设抽取 `h` 次）
- 累计缺陷数 `xn`
- 拒收水平：`Bn`（每次新样本后更新）
- 接受水平：`An`（每次新样本后更新）
- 不确定区域：介于 `An` 和 `Bn` 之间
- 抽样上限：`nk`

图示含义：

- 位于 `An` 以下：接受
- 位于 `Bn` 以上：拒收
- 位于两者之间：继续抽样

---

## 序贯概率比检验（Wald, 1947）

假设：

```text
H0: p = p0  （原假设）
H1: p = p1  （备择假设）
```

累计对数似然比：

```text
S0 = 0
Si = S(i-1) + log Λi, i = 1,2,...
```

停止条件：

1. `a < Si < b`：继续监测
2. `Si ≥ b`：接受 `H1`
3. `Si ≤ a`：接受 `H0`

近似边界：

```text
a ≈ log[β / (1 - α)]
b ≈ log[(1 - β) / α]
```

---

## 序贯抽样计划：数学原则

设 `xn` 为样本量为 `n` 时的累计缺陷数。

假设：

```text
H0: p = p0
H1: p = p1
```

其中：

- `p`：缺陷百分比
- `p0`：NQA
- `p1`：NQL
- `pn0`：在假设 `H0` 且 `p = p0` 时，样本量 `n` 下出现 `xn` 个缺陷的概率
- `pn1`：在假设 `H1` 且 `p = p1` 时，样本量 `n` 下出现 `xn` 个缺陷的概率

概率比：

```text
Rn = pn1 / pn0
```

累计缺陷数形式：

```text
x1
x1 + x2
x1 + x2 + x3
x1 + x2 + x3 + ... + xh
```

---

## 序贯抽样计划：边界公式

设：

```text
An = -g0 + kn
Bn =  g1 + kn
```

其中：

```text
p0 = NQA
p1 = NQL
α = 生产者风险
β = 消费者风险
```

并有：

```text
C0 = log[(p1 / p0) × ((1 - p0) / (1 - p1))]

g0 = (1 / C0) × log[(1 - α) / β]

g1 = (1 / C0) × log[(1 - β) / α]

k = (1 / C0) × log[(1 - p0) / (1 - p1)]
```

抽样上限：

```text
nk = g0 × g1 / [k(1 - k)]
```

不确定区间宽度：

```text
Bn - An = g1 + g0
```

---

## 序贯抽样计划示例

给定：

```text

Bn =  3 + 0.08n
```

参数：

```text

```
