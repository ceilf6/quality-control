## 制造控制：引言

为了保证绩效，企业有两个目标：

1. 确保关键特性的变异性与客户期望相兼容  
   → **过程能力 / 能力指数（Capabilité）**

2. 确保变异性保持“稳定”，且不会出现不良趋势  
   → **控制图（Cartes de contrôle）**

## 制造控制：过程能力

如果一个过程处于稳定状态，也就是处于统计受控状态，则：

- 中心趋势随时间保持在期望值附近；
- 离散程度随时间保持稳定；
- 可归因原因被消除。

### 原因分类

**不可归因原因**：

- 过程本身固有的原因；
- 属于自然变异。

**可归因原因**：

- 可以识别；
- 通常是孤立影响。

例如：

- 机器失调；
- 操作员因素；
- 工具磨损。

## 制造控制：过程能力指数

页面给出：

- **D**：包含 99.73% 产品的区间；
- **IT**：客户规格区间；

公式：

```text

```

其中：

- IT 表示客户规格区间；
- D 表示过程的自然离散区间，通常对应 6σ。

## 制造控制：机器能力指数 Cm 与 Cmk

机器能力指数：

```text
Cm = IT / (6σ*) = (Ts - Ti) / (6σ*)
```

机器被认为具有能力的条件：

```text
Cm > 1.33
```

机器能力居中指数：

```text
Cmk = min{ (Ts - X̄) / (3σ*) ; (X̄ - Ti) / (3σ*) }
```

其中：

- Ts：规格上限；
- Ti：规格下限；
- X̄：样本均值；
- σ*：估计标准差。

Cmk 用于同时检查：

- 离散程度；
- 均值是否居中。

## 制造控制：Cm / Cmk 决策逻辑

页面展示了基于 Cm 和 Cmk 的判断流程：

1. 计算 Cm 与 Cmk。
2. 判断 Cm 是否小于 1.33。
3. 判断 Cmk 是否小于 1.33。
4. 根据结果判断机器是否满足要求。

可能情况：

- 机器对离散程度有能力，且居中良好；
- 机器对离散程度有能力，但未居中，需要调整；
- 出现不可能情形，需要重新检查计算或数据；
- 机器离散程度不合格，即使居中也不能满足要求，需要干预。

## 控制限 vs 公差限

### 公差限

用于判断一个零件是合格还是不合格，从而决定是否接受或拒绝一批产品。  
公差限来自客户规格。

### 控制限

用于判断过程是否仍然围绕目标值稳定运行。  
控制限的目的不是直接判定单个零件好坏，而是帮助操作者对过程进行调整，以保证未来生产的零件仍然合格。

常见标记：

- LIC：控制下限；
- LIT：公差下限；
- LST：公差上限；
- LSC：控制上限。

---

## 控制图的使用原则

控制图使用步骤：

1. 确定控制限和监督限；
2. 绘制控制图；
3. 将观测值记录在图上；
4. 分析并得出结论。

判断规则：

- 若出现超出边界的点，则说明可能存在问题或异常；
- 否则，认为过程处于受控状态。

---

## 控制图类型

### 计量型控制图

用于可测量的特性，例如：

- 直径；
- 重量；
- 寿命。

常见形式：

- 均值 — 极差图：X-bar / W；
- 均值 — 标准差图：X-bar / S；
- CUSUM 与 EWMA：用于检测较小的漂移；
- 其他。

### 计数型控制图

用于不可连续测量、以属性计数表示的特性，例如：

- 缺陷品比例；
- 缺陷数量；
- 扣分数。

常见形式：

- np 图：缺陷品数量；
- p 图：缺陷品比例；
- c 图：缺陷数；
- 其他。

## 抽样大小与抽样频率

样本大小 n，根据 NF X06.031：

- 计量型控制图：2 到 12；
- 计数型控制图：10 到 50。

抽样次数 k 取决于：

- 不良质量成本，例如报废或返工；
- 班组、工具、材料批次的变化；
- 生产节拍；
- 其他因素。

---

## 抽样大小与频率：两种方法

### 方法 1

通常抽取大小为 4、5 或 6 的样本。

若每小时生产数量的 5% 到 10% 需要抽检，则根据样本大小确定抽样频率。

### 方法 2

设：

- C：机器小时产量；
- n：每次抽取的零件数量；
- N：两次调整之间生产的零件数量。

则：

```text
每 n 个零件抽检一次，对应每 n × N 个零件抽一次
```

换算为时间：

```text
n × N × 60 / C 分钟
```

---

## 示例：抽样频率

### 方法 1

如果每小时生产 300 件，抽样比例为 5%。

则每小时共抽检：

```text
300 × 5% = 15 件
```

如果每次抽 5 件，则：

```text
每 20 分钟抽取 5 件
```

### 方法 2

设：

- C = 200 件/小时；
- N = 400 件；
- n = 5。

页面给出的计算为：

```text
一次抽取 n = 5 件，对应 n × N = 45 件
```

即每次抽 5 件的时间间隔为：

```text
45 × 60 / 200 = 13 分 30 秒
```

> 注：原文中 “n × N = 45 件” 与给定 n=5、N=400 在数学上不一致，此处按原页内容翻译保留。

## 计量型控制图

假设：

- 被测特性 X 服从正态分布：

```text
X → N(μ, σ)
```

如果直接变量不满足要求，则取大小为 n 的样本。

样本均值服从：

```text
X̄ → N(μ, σ / √n)
```

控制图用于跟踪平均特性。

## X-bar 均值图与 W 极差图的控制限

页面展示了离散程度估计表，包括：

- 每个样本的观测值；
- 样本均值；
- 样本标准差；
- 极差 R。

公式：

```text
σ_i = sqrt( 1/n × Σ(X_ij - X̄_i)^2 )
```

```text
R_i = Max(X_ij) - Min(X_ij)
```

```text
X̄_i = 1/n × ΣX_ij
```

## 均值图：σ 已知时

当 σ 已知时，对于样本大小为 n、样本均值为 X̄：

控制上限：

```text
LCs = X̄ + 3σ/√n = X̄ + Acσ
```

控制下限：

```text
LCi = X̄ - 3σ/√n = X̄ - Acσ
```

监督上限：

```text
LSs = X̄ + 2σ/√n = X̄ + Asσ
```

监督下限：

```text
LSi = X̄ - 2σ/√n = X̄ - Asσ
```

不同参数需查表获得。

---

## 均值图：σ 未知时

当 σ 未知时，对于样本大小为 n、样本均值为 X̄：

需要估计 σ。

使用样本标准差均值：

```text
σ̄ = 1/k × Σσ_i
```

```text
σ* = σ̄ / b_n
```

使用平均极差：

```text
R̄ = 1/k × ΣR_i
```

```text
σ* = R̄ / d_n
```

考虑公差时，系数会根据所使用的离散估计量改变：

| 使用的估计量 | 系数 |
|---|---|
| σ* | Ac 和 As |
| σ̄ | A'c 和 A's |
| R̄ | A''c 和 A''s |

## 控制图使用流程

1. 每隔 h 小时抽取大小为 n 的样本。
2. 计算 X̄，并将其记录在控制图上。
3. 如果 X̄ 位于两个监督限之间，则继续进行下一次抽样。
4. 如果 X̄ 位于监督限和控制限之间，则再次抽样确认。
5. 如果 X̄ 超出控制限，则进行调整和试验。

## 控制限与规格限

在考虑估计值 σ* 时，若：

```text
Cp > 1.5
```

则均值图控制限可以结合规格限计算：

```text
UCL(X̄) = USL - 3σ* + 3σ*/√n = USL - 3σ* + Acσ*
```

```text
LCL(X̄) = LSL + 3σ* - 3σ*/√n = LSL + 3σ* - Acσ*
```

其中：

- USL：规格上限；
- LSL：规格下限。

## 控制图解释

控制图常分区：

- Zone A：靠近控制限区域；
- Zone B：中间区域；
- Zone C：靠近中心线区域。

上下两侧分别对应：

- 3σ；
- 2σ；
- 1σ。

---

## 过程受控的条件

一个过程可认为处于受控状态，如果：

- 没有样本点超出控制限；
- 大多数点接近过程平均值；
- 中心线上方和下方的点数量大致相等；
- 点看起来是随机分布的。
