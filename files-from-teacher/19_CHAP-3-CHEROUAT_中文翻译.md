## 第 16 页

# 逻辑回归

- 用于二分类，而不是连续值回归。
- 使用 Sigmoid 函数预测概率。
- 属于监督学习方法，用于分类问题。

示例：缺陷 / 无缺陷，是 / 否，0 / 1。

# 支持向量回归（SVR）

- 在容忍边界（epsilon-insensitive）内拟合函数。
- 适合通过核技巧处理非线性回归。
- SVR 会忽略小误差，重点关注大误差。

与普通回归尽量靠近所有点不同，SVR 在曲线周围建立一个容忍区域（称为“间隔”）。

## 第 18 页

# 线性回归与逻辑回归的计算形式

线性回归：

```text
y = c + X1*w1 + X2*w2 + X3*w3 + ... + Xn*wn
```

基于输入变量 X 的加权和来预测一个实值输出 y。

逻辑回归：

```text
y = logistic(y) = 1 / (1 + e^[-(c + X1*w1 + X2*w2 + ... + Xn*wn)])
```

- 如果输出 > 0.5 → 分类为 1（或正类）
- 如果输出 < 0.5 → 分类为 0（或负类）

## 第 19 页

# 伯努利分布

伯努利分布由一个参数刻画：

- `p`：成功概率
- `1 - p`：失败概率
- `X`：随机变量

伯努利分布是一种非常简单的概率分布，用于建模只有两种可能结果的随机实验：成功或失败。

示例：

- 成功概率 30%：P(X=1)=0.3，P(X=0)=0.7
- 成功概率 50%：P(X=1)=0.5，P(X=0)=0.5
- 成功概率 70%：P(X=1)=0.7，P(X=0)=0.3

两根柱子分别表示失败概率（X=0）和成功概率（X=1）。柱子的高度根据 p 的值变化，总和为 1。

## 第 20 页

# 均值与方差

## 均值（期望）

```text
E[X] = p
```

如果重复进行很多次伯努利试验，平均结果会收敛到 p。

## 方差

```text
Var(X) = σ² = p(1 - p)
```

当 p = 0.5 时，方差达到最大；当 p 接近 0 或 1 时，方差减小。

方差越大 → 不确定性越高。

## 伯努利概率密度函数

```text
f(y;p) = 1 - p,  当 y = 0
f(y;p) = p,      当 y = 1
```

也可写为：

```text
f(y;p) = p^y(1-p)^(1-y), y ∈ {0,1}
```

在质量控制中：

- X = 1 → 零件合格
- X = 0 → 零件缺陷

如果 p = 0.9，则 90% 的零件合格，10% 的零件有缺陷。

## 第 21 页

# 线性回归

## 简单线性回归

- `y`：要预测的变量（因变量）
- `x`：输入变量（自变量）
- `a` 或 `w`：系数（斜率或权重）
- `b`：常数项（截距）

```text
y = ax + b
```

## 多元线性回归

多个变量：

```text
y = b0 + b1*x1 + b2*x2 + ... + bn*xn
```

模型目标：最小化真实值与预测值之间的误差。

损失函数（MSE）：

```text
MSE = (1/n) Σ(y_real - y_pred)^2
```

目标是找到最能代表数据的直线。

为了计算截距 b 和权重 w，需要使用优化算法（梯度下降、Newton-Raphson，或 scikit-learn 等库），最小化模型预测概率与真实标签之间的 log-loss（交叉熵损失）。

## 第 22 页

# 逻辑回归与 Sigmoid 函数

逻辑回归预测一个 0 到 1 之间的概率：使用 Sigmoid（逻辑）函数。

它将线性组合转换为概率：

- 如果概率 ≥ 0.5 → 类别 1（或正类）
- 如果概率 < 0.5 → 类别 0（或负类）

阈值可以根据问题进行调整。

示例：

```text
P(缺陷 = 1 | 温度, 湿度) = 0.8
```

表示有 80% 的概率发生缺陷。

Sigmoid 曲线特征：

- 曲线平滑地从 0 过渡到 1
- 当 x = 0 时，σ(x)=0.5
- 函数关于原点具有对称性

# 选择回归算法的步骤

## 1. 理解问题

- 定义问题：目标变量（因变量）是什么？预测变量（自变量）是什么？
- 理解领域：变量之间是否存在领域知识？

## 2. 理解数据

- 关系是线性还是非线性？
- 数据是否存在异常值或噪声？
- 是多个特征还是一个特征？
- 目标变量是连续型（适合回归）还是类别型？

## 3. 选择合适的回归算法

- 线性回归：当自变量与目标变量之间存在线性关系时使用。
- 多项式回归：当关系是非线性的，但可以用多项式表达式建模时使用。
- 支持向量回归（SVR）：适合非线性关系，并能处理高维特征空间。
- 神经网络：当数据集较大、关系复杂时，可用深度学习模型执行回归任务。

## 4. 划分数据

- 训练集：用于训练模型
- 测试集：用于评估模型性能

常见做法是 80-20 划分（80% 数据用于训练，20% 用于测试），但比例可根据数据规模调整。

在测试数据上评估，使用合适指标：

- MAE（平均绝对误差）

也可使用散点图或残差图比较预测值与真实值。

## 第 26 页

# 损失函数

机器学习中的损失函数是一个数学函数，用于度量模型预测值与真实目标值之间的差异。训练模型的目标是最小化损失函数，从而提升性能。

## 回归损失函数

### 1. 均方误差（MSE）

- 常用于回归任务。
- 衡量预测值与真实值差异平方的平均值。
- 对大误差惩罚更强。

### 2. 平均绝对误差（MAE）

- 也用于回归任务。
- 衡量预测值与真实值绝对差异的平均值。
- 比 MSE 更抗异常值，但对大误差可能不够敏感。

---

## 第 27 页

# 分类损失函数

交叉熵损失用于衡量：在分类问题中，模型错得有多严重。

模型输出概率：

- 预测：0.9（90% 不合格）
- 实际：1（不合格）
- → 好预测，误差小

相反：

- 预测：0.1
- 实际：1
- → 差预测，误差大

其中：

- `y`：真实值（0 或 1）
- `p`：预测概率

```text
L = -[y log(p) + (1-y) log(1-p)]
```

---

## 第 28 页

# 交叉熵损失（Log Loss）

- 常用于分类任务，尤其是二分类或多分类。
- 衡量两个概率分布之间的差异：真实分布（真实标签）和预测分布（模型输出概率）。
- 二分类公式：

```text
Cross-Entropy = -(1/n) Σ [y_i log(ŷ_i) + (1-y_i) log(1-ŷ_i)]
```

- 用于二分类（例如垃圾邮件 / 非垃圾邮件）。
- 对“非常自信但错误”的预测惩罚很重。

`np.clip(a, a_min, a_max)` 用于裁剪数组中的值。给定一个区间，区间外的值会被限制到边界值。

示例：

```text
np.clip([1,2,3,4,5,6,7,8], a_min=2, a_max=6)
输出：[2,2,3,4,5,6,6,6]
```

## 第 29 页

# Hinge Loss（合页损失）

- 用于支持向量机（SVM）的分类任务。
- 合页损失会惩罚错误分类，并要求正确类别与预测类别之间有一定间隔。
- 用于二分类问题。
- 目标不仅是分类正确，还要“带有安全间隔地正确”。

其中：

- `y`：真实类别（+1 或 -1）
- `f(x)`：模型预测分数

情况：

1. 正确预测且有足够间隔：`y*f(x) ≥ 1`，损失 = 0，模型满意。
2. 正确但信心不足：`0 < y*f(x) < 1`，损失 > 0，模型需要增大间隔。
3. 错误预测：`y*f(x) < 0`，损失高，惩罚大。

## 第 30 页

# Huber Loss

- MSE 和 MAE 的组合。
- 比 MSE 对异常值不那么敏感，比 MAE 更平滑、鲁棒。

δ 是阈值参数，用于控制平方误差和线性误差之间的转换。

- 当误差较小时，表现得像 MSE（保证平滑梯度）。
- 当误差较大时，表现得像 MAE（减少异常值影响）。

选择 δ：

- 默认值通常为 1.0，但取决于数据尺度。
- δ 小：更像 MAE。
- δ 大：更像 MSE。

## 第 31 页

# 回归模型评估指标

## MAE（平均绝对误差）

预测值与真实值绝对差异的平均值。

- 对异常值较鲁棒，但不会特别重罚大误差。
- 易解释（与输出单位一致）。

## MSE（均方误差）

预测值与真实值差异平方的平均值。

- 对异常值敏感。
- 当大误差特别严重时很有用。

## RMSE（均方根误差）

MSE 的平方根。单位与目标变量一致，因此更容易解释。

## R²（决定系数）

衡量模型对数据的拟合程度，范围通常从 0 到 1。

- 1：完美预测
- 0：模型和只预测均值一样差
- < 0：模型比只预测均值还差

# 线性回归

使用最小二乘法估计线性方程中的斜率 `b` 和截距 `a`，根据预测变量 X 的值预测结果变量 Y。

```text
Y = a + bX
```

## 第 34 页

# Pearson 相关系数

Pearson 积矩相关系数（记作 r）用于衡量两个连续变量之间的线性关系。

相关系数 r 的取值范围为：

```text
[-1, 1]
```

解释：

- r = 1：完全正线性相关
- 1 > r > 0.8：强正相关
- 0.8 > r > 0.4：中等正相关
- 0.4 > r > 0：弱正相关
- r = 0：无相关
- 0 > r > -0.4：弱负相关

# 最小二乘损失函数

最小二乘损失是回归任务中最常用的损失函数之一。它通过对预测值与真实值之间的差异平方来衡量预测值与真实值的接近程度。

优化目标是找到使损失最小的模型参数：

```text
Mean Squared Error
```

其中：

- `H`：模型参数
- `1/2`：用于简化损失函数对参数求导时的表达式

确定假设函数 H 的最佳参数 `(w0, w1)`，等价于找到一条最佳直线，使所有样本误差之和最小。

## 第 53 页

# 梯度下降更新规则

梯度下降是机器学习中的关键优化算法，它允许调整模型参数以最小化代价函数。

步骤：

1. 初始化 `(w0, w1)`
2. 不断更新权重直到收敛：

```text
w0 := w0 - α * ∂C/∂w0
w1 := w1 - α * ∂C/∂w1
```

其中：

```text
∂C/∂w = 2Xᵀ(Xw - y)
```

`α > 0` 是学习率，需要选择一个参数，通常较小，例如 0.01 或 0.001。

第 2 步会重复执行，直到达到停止条件，例如固定迭代次数，或 `(w0, w1)` 的变化变得很小。

# 梯度下降与拟合线

- 通过最小化平方误差学习最佳拟合直线。
- 红线表示学到的线性模型。

随着梯度下降优化模型，损失（均方误差）会随时间下降。

曲线通常从较高值开始并逐渐变平，表示模型正在收敛到最佳拟合直线。
