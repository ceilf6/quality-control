第一部分 控制图导论 Introduction to Control Charts
【课件 P1】 控制图的用途 (Uses of the control chart)
• 大多数过程并不天然处于统计受控状态 (state of statistical control)；
• 认真使用控制图能识别出可查明原因 (assignable causes)；消除它们后变异减小、过程改善；
• 控制图只负责"检测"可查明原因——真正消除原因要靠管理者、操作工和工程师的行动。

 考点 / 提示：核心概念：变异分两类——普通原因 (common/chance cause)
 是过程固有、随机的；可查明原因 (assignable cause)
 是异常的、可定位可消除的。控制图就是用来"抓"后者。

【课件 P5】 p 图：监控不合格品比例
• p 图用于控制样本中不合格品所占比例；样本不必完全相同 (大小可变)；
• 可有效发现某产品/服务不合格率是否发生了漂移 (shift)；
• 应用举例：不完整订单、延迟交付、漏接电话、记账错误、装配不良零件等。

【课件 P16–18】 c 图：监控缺陷总数
  "不合格品" vs "缺陷" (defective vs defect)
• 不合格品 (defective)：不符合某规范的整件产品；

• 传统    图的局限：对过程均值的小幅漂移不敏感（要好几点才报警）；
• CUSUM (Cumulative Sum) 通过把"每次观测与目标值之差"累加起来，放大小漂移，能更快检测；
• CUSUM 有两种等价版本：图解版 (V-mask) 和 计算版 (tabular/computational)。

就判过程失控。

    V-mask 参数 d 与 θ 的选择
• d：罩顶到当前点的水平距离；θ：罩臂半张角；h：决策高度；
• 选 d、θ 使得：① 受控时误报警 (false alarm) 极少；② 均值出现重要变化时能快速检出。

【课件 P29】 判异规则与计数器
• 决策区间 H：C       或 C   超过 H 即判过程失控；经验值 H=5σ；
• 计数器 N     、N   ：分别记录 C   、C   连续大于 0 的期数；
• 计数器可用来推断漂移最可能发生的时刻（往回数 N 期）。

【课件 P34–35】 平均运行长度 ARL
平均运行长度 (Average Run Length, ARL) 是"平均多少个点才报警一次"，用来选择样本量与抽样频率
：

其依据是几何级数求和：

k=1.5                  14.97                     1.56                1.20

k=2                    6.30                      1.07                1.01

    限）；② 漂移越大 (k↑) 或样本越大 (n↑)，ARL 越小→检出越快。这就是"加大 n
    能更快发现漂移"的量化依据。
