抽样检验里，样本不合格数 X 为什么常近似服从二项分布？

直观想法是：每抽一件，都在做一次“这件是不合格吗”的判断。只要这种判断满足固定次数、两种结果、概率近似不变，样本中的不合格数就常写成二项分布。

什么时候可用二项分布？

  • 每次抽取只有两种结果：合格 / 不合格
  • 总共抽样 n 次，样本量固定
  • 每次“不合格”的概率近似相同，记作 p
  • 总体足够大时，不放回抽样也常近似看成相互独立

于是就写成

X ~ B(n, p)
P(X = x) = C(n, x) px(1-p)n-x
意思是在 n 件样品里，恰好有 x 件不合格的概率。

考试里容易混的补充

如果总体不大，而且是不放回抽样，严格说更适合用超几何分布。
但很多题默认总体足够大，所以会写“样本不合格数 X 通常服从二项分布”。
一句话记忆：每件样品都像一次“是否不合格”的伯努利试验，n 次累加起来，不合格数 X 就常按二项分布处理。
